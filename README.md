# CraySafe
## IoT-Based Water Quality Monitoring System for Sustainable Crayfish Aquarium Management

### About
CraySafe is an IoT-based water quality monitoring system designed for sustainable crayfish aquarium management. The app monitors temperature, pH, and turbidity levels in real-time.

### Features
- User Authentication (Login/Register)
- Dashboard with real-time tank monitoring
- Alerts for water quality changes
- Historical reports and analytics
- Diagnostic Q&A support

### Tech Stack
- **Mobile:** Kotlin, Android SDK
- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **Hardware:** Orange Pi, pH/Temperature/Turbidity sensors

### Prerequisites
- Android Studio Arctic Fox or later
- Java 11+
- Android SDK (API 24+)

### Getting Started
1. Clone the repository:

   git clone https://github.com/YOUR_USERNAME/CraySafe.git
2. Open project in Android Studio
